# Qualys API (VM/PC) Postman collection

## Status

In preparation. No Qualys API (VM/PC) Postman collection has been published yet.

## Intended coverage

The completed collection will provide a structured reference for documented VMDR, Policy Audit, and shared-platform API endpoints, supported versions, and input parameters. It will identify source documentation, distinguish documented coverage from live verification, and show published EOS/EOL status and dates for every versioned endpoint. See [COVERAGE.md](COVERAGE.md) for the initial family-level register.

## Scope boundary

This first release is a Postman reference collection. It does not include customer-specific workflows, tag-management automation, or bundled tenant data.
